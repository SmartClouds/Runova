## Run the tests where the agent works

Runova finds the test setup in a project and runs it from the Tests tab in the workspace side panel. It knows Vitest, Jest, Playwright, Mocha, pytest, unittest, Go, cargo, .NET, Dart, Flutter, PHPUnit, RSpec, Gradle and Maven.

<Screenshot name="workspace" />

## Results while the run is still going

Results stream in as the runner reports them, with a clock that shows how long the run has taken so far. The results are a tree of files and test cases you can filter, and the raw output of the runner is one click away when you want every line.

## Send the failures to an agent

When tests fail, **Fix with AI** hands the failures to an agent, so the one that wrote the code can fix it while you keep reviewing.
