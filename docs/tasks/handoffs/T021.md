## Decisions

- Leg 1 decisions stand (one role per account in the UI, `If-Match` from the DTO version, 403 by
  rewrite, default overlap 1 day, fragment stripped on set-password).
- `docs/website/examples/package.json` (`"type": "module"`) lets Playwright import the reference
  signing client, which uses `import.meta`. That fixes the cause, so the spec imports it statically.
- Signed checks use a fresh request context without cookies, so the session can't authorize them.
- The Jobs link uses section `hangfire` so it is never marked current on `/admin`.

## Tried and rejected

- Dynamic `import()` and `new Function('return import(url)')` for the signing client: Playwright's
  loader still compiled it as CommonJS and Node refused the `require` of an ES module.
- Focusing the revoked note right after `await load()`: the note had not rendered yet, and Radix
  returned focus to the Revoke button, which then unmounted.
