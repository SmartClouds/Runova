## Purpose

Give staff an admin area on the site (worktree `E:/Runova-website`, branch `website`, folder
`apps/website/web`): sign-in with TOTP and sign-out, a news list and editor, a blog list and
editor, all under `/admin` (on demand, noindex, private, no-store), as React islands with
shadcn/ui calling `/api/v1` on the same origin.

## Decisions

- Leg 1 to 3 decisions stand (news PUT full DTO, posts PATCH merge patch, conflict wording and
  focus, field error placement, list status from `publishedAt`, `aria-disabled` paging, API on
  HTTPS behind the proxy, one Editor and session per worker, `/admin/set-password` is T021's).
- The tag race and the clock-bound cookies were fixed at the cause instead of making e2e tags
  unique or moving the pinned dates.
- Orphan tags from a failed save are harmless: the public tag list leaves out tags no published
  post carries.

## Tried and rejected

- Sending the post cover by PUT: impossible without the media id.
- A plain HTTP proxy for e2e: the API's antiforgery throws on non-HTTPS requests.
- `disabled` on the paging buttons: focus drops to the body on the last page.
- Moving the pinned test dates: about 25 literals in six files, and any fixed date runs out again.
- Rewriting every cookie's expiry: changed the sign-out cookie a test reads; expired ones stay.
