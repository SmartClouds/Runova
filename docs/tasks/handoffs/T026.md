## Decisions

- Caddy: `auto_https disable_redirects` plus its own `http://` block with a 308 to `{$HTTPS_PORT}`;
  Caddy serves `/media` from the media volume read-only.
- CI compose project `runova-e2e-website`, ports 18080 and 18443, job-level `concurrency: website-stack`.
- The hero calls 4 cores or 4 GB low-end, and the CI runner is that, so the specs that need the
  scene say what device they run on rather than depending on the machine.
- origin/website was filled through the Git Data API (`git push` over HTTPS timed out on packs over
  a few MB); every object SHA matched, so the branch is identical to the local one.
