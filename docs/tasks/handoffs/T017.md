## Decisions

- Detection runs on the server, with `Vary: User-Agent, Sec-CH-UA-*` and `Critical-CH:
  Sec-CH-UA-Arch` so Chromium on Apple silicon retries with the arch.
- Mac with unknown arch: the universal dmg if there is one, else both dmgs. Windows gets x64.
  Linux with unknown arch gets x64.
- Fallback (no release ever read): 200 with `public, max-age=60`, build-time version, GitHub
  Releases button, no table; JSON-LD `downloadUrl` is the Releases URL.
- e2e emulates systems with CDP `Emulation.setUserAgentOverride` and `userAgentMetadata`.
- No `customPages` in the sitemap config: `@astrojs/sitemap` already lists `/download`.

## Tried and rejected

- Playwright `userAgent` with `extraHTTPHeaders` or `page.route` for hints: Chromium sends the
  host's platform when it can't tell one from the UA, puts it back on the Critical-CH retry, and
  adds `Sec-CH-UA-*` after interception.
