## Decisions

- Leg 1 decisions stand (page size 10, paging in the path, Cache-Control per route, 404 and 503
  rules, no client cache, related posts, OG image via fontkitten and sharp, hand-written RSS).
- The page tests now load the React container renderer like `downloadPage.test.ts`: the header's
  theme toggle renders lucide-react icons, so the container fails without it.
- Help prose styles moved from `HelpLayout.astro` into `src/components/Prose.astro` (class
  `prose`), shared by help articles and post bodies.
- The Blog link is in the footer: the header already uses all of 320 px. Blog pages add an RSS
  `<link rel="alternate">` to the head.
- `e2e/helpBuild.spec.ts` now finds on-demand pages in folders too (`blog/index.astro` is `/blog`).
- `e2e/blog.spec.ts` answers `https://runovahq.com/media/**` with 404, so page loads never wait on
  the real site for fixture covers.
