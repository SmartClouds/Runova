## Decisions

- Leg 1 decisions stand (hashes not nonces, `'unsafe-inline'` for styles, the theme script hash,
  headers in a server around the adapter's `handler`, on-demand 404 and 500).
- `font-src 'self' data:`: Vite inlines the smallest font subsets as data URLs; the CSP e2e found it.
- The Lighthouse blog post is a release note: fixture covers are absolute runovahq.com URLs, which
  the CSP of a localhost build blocks, and that fails best practices (console errors).
- T026 (Dockerfile): run `bun scripts/server.ts`, not `dist/server/entry.mjs`, or the site loses
  HSTS, Referrer-Policy, X-Content-Type-Options and Permissions-Policy. Caddy may add them instead.

## Tried and rejected

- The adapter's own `startServer`: it serves prerendered files without Astro middleware, so it
  can't add the headers.
- A `config.sitemapOptions` key on the Astro config (leg 1): Astro validates the config.
