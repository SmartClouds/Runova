## Purpose

A News card on the Dashboard (E42, `docs/epics/42-dashboard-news.md` "The dashboard card"):
latest items with severity, category, unread and "Affects your system" badges, filters, states,

## Decisions

- The sheet's open item lives in the URL (`?news=<slug>`, replace), so the notification route and
  a row click share one path. Closing removes the param.
- The filter hook writes the saved settings back with `setQueryData` (not invalidate), so a stale
  `settings.get` cannot snap the menus back.
- View all only shows when `total > 5`. Critical in the severity menu reads `Critical only`.
- Dark tokens are set on `.dark` and inherited by the VS Code and VS 2026 themes.
- Before the first poll the card shows "No news yet." (no list), which is expected.
